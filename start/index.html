Get started

🖖 Everything you need to run Spock.

Plain English, no jargon. You will never type a terminal command beyond one paste. After that, you talk to it in ordinary words.

Set up — three steps, once
1

Install Claude Code on your Mac

It is a free app from the company that makes Claude. Roger will send you one link — click it and follow the prompts. It is a normal Mac install, like any other app.
2

Paste the one command Roger sends you

Roger will send you a single line of text, made just for you — it carries your personal key, so treat it like a password. Copy it, paste it into Claude Code, press Enter. That is the only command you will ever type. It looks like this:

SPOCK_API_TOKEN='…your key…' bash <(curl -fsSL '…')

Yours will have the real values already filled in. Don't share it.

3

Let it check itself

That command sets everything up and checks that everything works. When it is done it says, in green, "Spock is ready." If anything is missing, it tells you in one plain sentence exactly what to send Roger. Either way, you are done — you do not fix anything yourself.

That is it. From here on you never type a terminal command. You just talk to Spock.

Running a company

Type one line, then talk to it.

/spock-run <company name>

For example: /spock-run Discovery or /spock-run GoTyme. Then just talk to it in ordinary sentences. Spock drives the whole run; you make four calls along the way, when it stops to ask.

1Scope-lock

It shows what it will look at. You nod.

2The taste board

It offers thesis options. You pick one.

3The lever sheet

It shows the assumptions. You approve them.

4The final call

It hands you the memo and verdict. You decide.

A full run takes hours and pauses for you along the way — that is the design, not slowness. You can walk away between pauses; it waits. See the whole run →

If something looks wrong

One command, one action.

spock doctor

It runs a full health check and prints a list of green passes and any red failures. Take a screenshot of that list and send it to Roger. That is all you ever need to do — you do not diagnose or fix anything yourself. You can never make it worse by running it: it only looks, it does not touch anything.
