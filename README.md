# Spock by Chronos — built site

Static build artifact from [rogergrobler/spock-site](https://github.com/rogergrobler/spock-site).
Served via GitHub Pages at https://rogergrobler.github.io/spock-site-build/.

This repo contains only the rendered HTML/CSS/JS. The source is private.

To redeploy: run `GH_PAGES=1 npm run build` in the source repo, then push the contents of `out/` to this repo's `main`.
